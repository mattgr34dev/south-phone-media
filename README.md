# south-phone-media

Обои и рингтоны для телефона `south_phone`.

- `wallpapers/` — png, jpg, gif, webp
- `ringtones/` — mp3, ogg, wav

Чтобы добавить новый файл, положите его в нужную папку и запушьте. В телефоне он появится в течение 10 минут.
Название в списке берётся из имени файла: `Nokia Tune.mp3` → «Nokia Tune», `ring27.mp3` → «Рингтон 27».

Файл лучше не заменять под тем же именем: jsDelivr может до 12 часов отдавать старую версию.
